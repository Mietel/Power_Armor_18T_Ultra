# Android device tree for Ulefone Power Armor 18T Ultra (Power_Armor_18T_Ultra)

## Reference Image

`prebuilt/boot-twrp-havoc-ultra14.img` is a TWRP/Havoc boot image prepared
for the Ultra Android 14 stock boot. Its kernel and DTB match the stock Ultra
boot image; keep the original stock `boot.img` available before testing.
